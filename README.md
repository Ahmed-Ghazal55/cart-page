# Cart Page (Legacy Frontend Project)

An earlier e-commerce/cart-style frontend practice page built with HTML, CSS and JavaScript and related UI assets. The current `index.html` includes a Parachute-themed header and uses Slick assets.

## Run
Open `index.html` or serve the folder using `python3 -m http.server 8000` and visit http://localhost:8000/.

## Scope
A frontend exercise, not a verified checkout system, payment processor or production storefront. Confirm all interactive functionality in a browser before advertising specific features.
